This folder deals with simulating the raster scan of absorber as well as US along the z-axis(along depth), as opposed to the files 
lying inside the sensitivity folder which keeps the US fixed at a point and does a raster scan of the absorber along the x-axis(horizontally).

Note that things are slightly different here since the mesh files are not the .py versions here in this case, we have the basic .ipynb 
versions here, and we are running them, saving the data, and loading that data where we want.
